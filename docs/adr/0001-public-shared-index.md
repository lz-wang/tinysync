# /shared 作为公开索引页列出全部可服务共享

旧「发布」功能（/published/*path）刻意对不可服务资源返回同形 404，不向未认证方泄露资源存在性。v0.10 重构为「共享」时，我们决定 `/shared` 是一个**公开索引页**：任何能访问该端口的人都能看到全部可服务共享的名称、分享时间与过期时间。理由：TinySync 部署于 HomeLab 内网，索引带来的可用性（找链接、盘点过期时间）大于枚举风险。

## Considered Options

- 无索引、仅直链：延续不泄露哲学，但共享链接只能靠管理侧逐一复制，可用性差。
- 索引页带配置开关：灵活，但新增配置面与文档负担，HomeLab 规模下收益不成比例。

## Consequences

- 过期与禁用的共享在索引页**完全隐藏**（不灰显），失效资源的存在性不因索引而泄露。
- 直链侧维持同形 404；索引页是唯一主动暴露存在性的地方，边界清晰。
- 公开页面加 noindex，避免被搜索引擎收录。
